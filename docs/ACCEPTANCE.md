# Acceptance gates

Release gates cover: install/package root, health endpoint, canonical identity, Mode 188 admission, replay/proof integrity, render truth, menu coverage, host evidence labels, atlas roundtrip, package/tree integrity, responsive panel layout and donor quarantine.

A polished UI is not sufficient. A PASS requires executable tests plus preserved truth/evidence boundaries. Missing real-world evidence returns HOLD/NO_EVIDENCE rather than synthetic substitution.

Local validation for Genesis v1: 17 executable tests passed before publication, including address roundtrip, Mode 188, DEWEY-BAL, shortest-arc phase, shell/simplex, motion math, projection fingerprinting, frozen forecast, evidence-promotion blocking, proof-chain validation, plugin mutation denial, corpus quarantine, Hybrid Link containment, Earth geodesics, all-mode registry and bounded plugin execution.
